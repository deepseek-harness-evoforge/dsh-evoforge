# Retention reserves independent pre-Candidate Goal evidence

Capability-Absent Retention must replay an independently protected internal Goal rather than a static operator target, a reused holdout, or a post-Candidate case. A four-Goal Skill Evaluation Evidence Seal remains authoring/admission/holdout only; when a fifth or later independent Goal exists, the vault reserves one separately ranked sample exclusively for a Candidate-invisible Retention author, and Evaluation Envelope v5 binds its input digest, unique assembled Case Pack hash, and isolated run root. This costs a third governance-author call but preserves proposer/judge separation and gives the later Retention runner a real prior case without reintroducing external acquisition or configured evolution direction.
