# Runtime config cannot select Skill sources or evolution targets

`dsh-evolve` profile configuration now contains only private content-addressed storage, Workspace-scoped internal authoring/evaluation policy, and bounded recovery roots; repository/source catalogs, target Skills, static Case Packs, feedback/evaluator targets, and per-Skill promotion allowlists were removed because they let deployment configuration predetermine what should evolve and preserved the old Git acquisition architecture. ADR-0067 subsequently removed the Git-named materializer from the active runtime and replaced it with an exact internal Bundle repository; it must not be reintroduced as compatibility.
