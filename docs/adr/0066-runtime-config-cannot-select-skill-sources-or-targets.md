# Runtime config cannot select Skill sources or evolution targets

`dsh-evolve` profile configuration now contains only private content-addressed storage, Workspace-scoped internal authoring/evaluation policy, and bounded recovery roots; repository/source catalogs, target Skills, static Case Packs, feedback/evaluator targets, and per-Skill promotion allowlists were removed because they let deployment configuration predetermine what should evolve and preserved the old Git acquisition architecture. The remaining Git-named implementation is hard-sealed with zero sources only as a temporary internal bundle materializer and must be replaced rather than exposed as compatibility.
