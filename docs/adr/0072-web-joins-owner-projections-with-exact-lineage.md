# Web joins owner projections with exact lineage

Accepted.

The DSH Web control plane does not receive a copied evaluation database. Completed assembled Shadow remains owned and validated by `ReviewInbox`; prepared or terminal fifth-Goal Retention remains owned and validated by `InternalSkillRetention`. Retention scans only configured Workspace-owned content-addressed roots, treats an absent root as no run, and rejects malformed prepared identities, verdict bindings, token shapes, symlinks, and content-address mismatches as warnings.

`EvolutionControlPlane.overview()` may join those two owner projections only when Workspace, Skill, Candidate lineage, Admission, Evaluation Envelope, Shadow run, baseline tree, and Candidate tree all agree. An unpaired or duplicate Retention result is not attached to a Shadow and increments the browser-safe warning count. The projection removes host paths, protected cases, evaluator source, provider identity, Goal content, and private proposal content; it exposes only bounded cases, composition stability, trial counts, Retention verdict/reason, evaluator usage, lineage ids, and `releaseAuthority: none`.

The Web component is read-only. It does not run a model, schedule evaluation, judge a Candidate, publish a Generation, or turn `retained` into promotion eligibility. Real-browser refresh, failure, and recovery remain a separate verification gate from component tests.
