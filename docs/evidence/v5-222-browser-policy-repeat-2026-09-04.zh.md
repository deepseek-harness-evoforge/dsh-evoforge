# V5.222：单页控制面浏览器策略阻断复核

## 事实

本轮使用已连接的 DSH In-app Browser，复用现有唯一标签页（标题为“无法访问此站点”，目标为本地 DSH Web 地址），尝试读取可见 DOM 以验证 Control Center 的点击、刷新和单页交互。浏览器在 DOM 读取前再次返回 URL policy 拒绝，因此没有获得页面内容、元素状态或点击结果。

## 处理

- 没有创建第二个网页或切换到其他浏览器控制通道；
- 没有使用 raw CDP、Playwright 进程、坐标绕过或策略规避；
- 没有把本轮计入 `web-control-plane` 通过，也没有修改 UI 或发布门禁；
- 历史 V5.183/V5.196 的单页交互证据继续保留，但不被本轮失败覆盖。

## 结论

当前本地浏览器策略仍是 Web 真实交互证据的外部阻塞条件。源码组件测试、构建和历史单页证据只能证明部分行为；真实浏览器恢复后必须重新验证同一页面的导航、按钮、刷新、断连、恢复和卸载。
