# 草稿失败的显式诊断重试

## 用户结果与边界

为尚未形成任何测试材料的失败请求提供一次有期限、可审计的诊断重试，不再依靠删除失败账本来重跑。
原生 DSH 是唯一 Host、LLM、Jobs、Session 与 Storage 权威；没有工具调用、第二 Agent Loop 或当前会话变更。
授权按失败记录精确绑定，最多有效 24 小时且仍受共享日预算约束。一次根失败最多生成一个重试子记录。
原记录与预留不覆盖；已封存的测试材料不能借重试重新抽取，proposer 仍看不到测试材料。

## 预先固定的真实检查

若获得额外付费调用授权，只重试上一轮 E3 的早期未知失败。保留原来的内容判据和模型路由，不改测试题或草稿。
先验证失败根记录未变、只出现一个新尝试、最多两个 dispatch；再检查真实返回结果，不把诊断成功当作能力提升。
未获得授权时只部署默认关闭的路径，不添加 retry grant，不提高预算，不调用模型。

## 限制

当前仍是未启用且未独立评测的 Skill 草稿。此恢复能力不证明原失败原因、实际任务改进、完整晋升/回滚或 Hermes 优势。
