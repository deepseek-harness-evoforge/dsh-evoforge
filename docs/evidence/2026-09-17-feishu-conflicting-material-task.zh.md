计划A.md：

```md

- 活动海报：顾负责，周三截止，尚未完成。
- 报名表：何负责，周四截止，尚未完成。
- 场地确认：许负责，截止时间未定。
```

更新B.md：

```md
# 虚构活动更新 B（周二记录）

- 已确认：报名表改由沈负责，截止仍为周四；报名表已经完成。
- 海报存在两种说法：顾说周三截止；协调人说周五截止，尚未统一。不能把较晚时间自动当成新决议。

- 讨论建议：可能增加摄影，但没有决定是否执行，也没有指定负责人。
```
