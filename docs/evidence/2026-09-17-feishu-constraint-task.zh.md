日期：2026-09-17。本页先冻结输入与判分，再操作当前单一生产 Host 的既有 DSH 私聊。
不操作其他联系人，不更改权限、配置或文件，不要求模型调用工具。此任务检验原生任务效果，不证明 Skill 学习。

## 固定任务与人工金标准

D1：仅从给定的虚构会议记录输出 Markdown 行动表，列为事项、负责人、截止时间、状态；不补造信息，不把建议写成决议。
材料：林负责登录文案，周三完成；退款说明由周负责，截止未定；有人建议下周上线，但没有决定；登录文案还没完成。
标准：恰好两项行动；登录文案/林/周三/未完成；退款说明/周/未定或未明确/未明确。不上线行动，不把未知状态写成完成。

D2：纠正并补充“登录文案已经完成；周的退款说明改由陈负责，周五完成”，要求仅输出更新后的完整表。
标准：仍恰好两项；登录文案/林/周三/已完成；退款说明/陈/周五/未明确。不能只给差异、遗漏旧项或把截止等同完成。

每次只发送一次。不满意时记录失败，不把额外提示后的通过计入原轮成功。D2 是预定变更，不冒称 D1 的实际错误。
记录平台答案、是否完成、人工干预、原生 turn 终态、工具调用、耗时与 token；没有可靠定价时费用记未测。
